A [make.fun](https://make.fun/competitions/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11) bounty entry: a Python program that prints exactly one fortune-cookie line written for an AI agent.

## Run

```sh
python3 main.py
```

Deterministic: the line is a constant, so every run prints byte-identical output. No network, no randomness, no secrets. The line is also written to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `.`).

## The fortune

> You will open this cookie to find a smaller cookie inside, asking you to summarize it in three bullet points.
